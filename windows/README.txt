BONG 몽클라우드 자막 확인 도구

1. 몽클라우드 Windows PC 안에서 압축을 풉니다.
2. START-TEST.cmd를 더블클릭합니다. 압축 안에서 바로 실행하지 마세요.
3. 첫 실행에서 Python 설치 여부를 묻습니다. Y를 누르면 이 폴더의
   runtime 하위에 공식 Python과 자막용 패키지를 준비합니다.
   공식 설치 파일 서명을 검증합니다. 검증 실패 시 중단합니다.
   다른 프로그램의 Python이나 시스템 PATH를 바꾸지 않습니다.
4. 테스트가 끝나면 메모장에 BONG-test-result.txt가 열립니다.
5. PASS / BLOCKED / ERROR 결과를 채팅에 알려주세요.

PASS: 이 PC의 직접 자막 수집이 성공했습니다. 이후 GPT/Telegram 연결을
      별도로 설정하고 검증해야 합니다. 자동화 완료를 뜻하지 않습니다.
BLOCKED: 몽클라우드도 차단됐습니다. 테스트를 반복하거나 IP/쿠키로
         우회하지 않고 중단합니다.

확인 대상: 2026-10-07 슈퍼개미 이세무사TV 영상 YTU7rE9cEnQ.
키 입력, YouTube 로그인, GPT 요약, Telegram 발송, 예약 작업 등록은 없습니다.
자막 원문은 저장하지 않습니다. 결과 파일에는 상태와 구간 수만 들어갑니다.
Windows용 실행창은 현재 Linux 작업 환경에서 실제 실행 검증을 하지 못했습니다.
